# Leif Moller — Portfolio

My personal portfolio site, built to showcase my projects in embedded systems, control theory, and mechanical design as an Engineering Physics student at UBC.

**Live site:** 
[leifmoller.github.io](https://leifmoller.github.io)

## About

This site covers my background, highlighted coursework, and write-ups for a few of my projects. Currently including an aerodynamic simulation/interpolation tool and topology-optimized rear-wing mount for UBC Formula Electric, and a force-controlled robotic gripper.
I will continue to update the projects as I develop more!
